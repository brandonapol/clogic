# SPIKE-008 probe scripts

Human reproduction aids for [SPIKE-008](../../docs/research/008-scripter-midi-fx.md). Not run by CI, not
imported by `src/`. Needs a Mac with Logic Pro.

- `probe-globals.scripter.txt`: paste into Scripter's Script Editor, click Run Script, and read the Interactive
  Console. It reports which common JavaScript host globals (network, timers, file, module loading) exist
  inside Scripter. Record the Logic Pro and macOS versions with the result.
