## Commands used

```sh
pdftotext -layout LogicPro.pdf logicpro.txt
curl -sL -o adpla.pdf https://developer.apple.com/support/downloads/terms/apple-developer-program/Apple-Developer-Program-License-Agreement-English.pdf
pdftotext -layout adpla.pdf adpla.txt
curl -sL -o osa.pdf https://cdn.openai.com/osa/openai-services-agreement.pdf
gh api repos/apple/AudioUnitSDK --jq '.license.spdx_id, .pushed_at'
gh api repos/juce-framework/JUCE/contents/LICENSE.md --jq .content | base64 -d
curl -sL https://raw.githubusercontent.com/FFmpeg/FFmpeg/master/LICENSE.md
curl -sL https://www.gnu.org/licenses/old-licenses/lgpl-2.1.txt
```

npm licence tally: a short `node -e` script walking `node_modules/**/package.json` and counting the
`license` field (132 packages, Node v26.8.2, npm 11.19.1).
