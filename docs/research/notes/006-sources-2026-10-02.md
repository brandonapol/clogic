## Commands used

```sh
gh api repos/<owner>/<repo> --jq '[.license.spdx_id, .pushed_at, .stargazers_count, .description] | @tsv'
gh api "repos/wikibook/logic-pro-x-103/git/trees/master?recursive=1"
gh api "repos/phierceweb/logicxkit/git/trees/HEAD?recursive=1"
gh api repos/rhydlewis/lpx-explorer/contents/docs/logicx-format.md --jq .content | base64 -d
gh search code "SongSignatureNumerator" --limit 20 --json repository,path
curl -sfL -o <file> https://raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>
od -A x -t x1z -N 64 ProjectData
python3 -B research/006-project-file-introspection/inspect_logicx.py /tmp/s006/p.logicx
python3 -B research/006-project-file-introspection/inspect_logicx.py /tmp/s006/q.logicx
```

Python 3.14.7 on Linux; `plistlib` from its standard library.
