MongLong observation records read (all under `docs/observations/`):

- `2026-09-08-mcu-feedback-is-decoded-as-if-it-were-midi-1.json`: 161 packets from Logic after binding;
  UMP decoding pitfall.
- `2026-09-11-the-mcu-plane-was-never-connected-and-plug-in-mode-works.json`: nothing works until a
  Mackie Control is installed in Setup; plug-in mode remaps V-Pots, LCD shows `Cha EQ`.
- `2026-09-13-the-mcu-lcd-upper-row-names-the-visible-strips.json`: 6-character names, collisions,
  output and master strips in the last bank.
- `2026-09-15-the-setup-windows-own-menu-installs-the-surface.json`: installing via the Setup window;
  "Reset defaults" learns port names but installs no device.
- `2026-09-27-en-US-mcu-set-arm-sets-instead-of-toggling.json`: arm is a toggle; clamped last bank.
- `2026-10-01-en-US-mcu-write-warning-is-acknowledged-before-the-reply.json`: Write automation raises a
  modal dialog.
- Source comment in `Sources/LogicProMCP/MIDI/MCUProtocol.swift`: Logic "doesn't reliably emit a
  discrete Device Response".
