# SPIKE-005 sources log (2026-10-02)

Related: [SPIKE-005](../005-accessibility-automation.md), issue
[#5](https://github.com/brandonapol/clogic/issues/5).

Every source used for SPIKE-005, with the version or date it states and how it was read. All fetched on
2026-10-02 from Linux; no Mac or Logic Pro was available. "Apple doc JSON" means the page's DocC JSON at
`https://developer.apple.com/tutorials/data/documentation/<path>.json`, read with a small Python script,
because the HTML pages render client-side. Logic Pro User Guide pages were fetched with `curl` and
reduced to text; the page's version selector showed Logic Pro for Mac 12.3 as the newest version.
